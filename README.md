# directed_mst

Минимальное ориентированное остовное дерево (минимальная арборесценция).  
Реализация трёх алгоритмов на языке C.

## Описание

Данный проект находит **минимальное ориентированное остовное дерево** (Minimum Cost Arborescence) во взвешенном ориентированном графе. Задача заключается в выборе набора рёбер минимальной суммарной стоимости, такого, что из заданной корневой вершины достижимы все остальные, и в графе нет циклов.

## Как это работает

### Проблема

Дан ориентированный граф с весами на рёбрах и выделенная корневая вершина. Нужно найти **минимальное ориентированное остовное дерево** (арборесценцию) — набор рёбер, такой что:

1. Из корня можно добраться до любой вершины
2. В выбранном наборе нет циклов
3. Суммарный вес рёбер минимален

### Алгоритмы

В проекте реализованы три подхода:

| Алгоритм | Сложность | Идея |
|----------|-----------|------|
| **Эдмондс (простой)** | O(n·m) | На каждом шаге выбираем минимальное входящее ребро для каждой вершины. Если образуется цикл — сжимаем его в одну вершину. Повторяем, пока циклов нет. |
| **Эдмондс с бинарной кучей** | O(m log n) | Та же логика, но для выбора минимальных рёбер используется бинарная куча (приоритетная очередь), что ускоряет работу. |
| **Габов–Тарьян** | O(m + n log n) | Улучшенная версия с фибоначчиевой кучей, дающая лучшую теоретическую асимптотику. |

### Что делает программа

1. Читает граф из файла
2. Проверяет, что все вершины достижимы из корня (BFS)
3. Запускает все три алгоритма по очереди
4. Для каждого замеряет время работы
5. Выводит результат (стоимость дерева) и время

## Сборка

```bash
gcc -Wall -Wextra -O2 -Iinclude tests/test_all.c src/*.c -o test_all.exe ```
```bash
test_all.exe data/sample.gr 0```
Где:
data/sample.gr — путь к файлу с графом
0 — номер корневой вершины (вершины нумеруются с 0)
