# directed_mst

Минимальное ориентированное остовное дерево (минимальная арборесценция).  
Реализация трёх алгоритмов на языке C.

## Описание

Данный проект находит **минимальное ориентированное остовное дерево** (Minimum Cost Arborescence) во взвешенном ориентированном графе. Задача заключается в выборе набора рёбер минимальной суммарной стоимости, такого, что из заданной корневой вершины достижимы все остальные, и в графе нет циклов. Это классическая задача, применяемая в проектировании сетей, синтаксическом разборе и других областях.

## Основной функционал

- **Три независимые реализации:**
    - **`edmonds_simple`** — классический алгоритм Эдмондса (Чу-Лю/Эдмондса) со сложностью **O(n·m)**. Использует прямой перебор рёбер.
    - **`edmonds_opt`** — оптимизированная версия с бинарной кучей, сложность **O(m log n)**.
    - **`gabow_tarjan`** — алгоритм Габова–Тарьяна с фибоначчиевой кучей, целевая сложность **O(m + n log n)**.
- **Работа с произвольными весами:** Алгоритмы корректно обрабатывают отрицательные веса рёбер (при условии отсутствия отрицательных циклов в сокращённом графе).
- **Проверка достижимости:** Выполняется BFS из корня. Если не все вершины достижимы, программа сразу сообщает `NO`, не запуская основные алгоритмы.
- **Сравнительный анализ:** Программа `test_all.c` последовательно запускает все три алгоритма на заданном графе, измеряет время работы и выводит три результата, которые должны совпадать.
- **Подготовленные тесты:** В папке `data/` находятся 10 тестовых графов разного размера (от 10 до 600 вершин).
